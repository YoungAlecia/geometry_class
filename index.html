Lesson Integration Guide

Swap the default GeoGebra activity for any classroom material in five short steps.

  1. Find the material on GeoGebra

    Sign in at geogebra.org/materials and open any resource. The URL ends with the material ID, e.g. geogebra.org/m/RHYH3UVE.

  2. Copy the material ID

    The ID is the alphanumeric segment after /m/. Material IDs are usually 8–12 characters.

  3. Paste it into the lab loader

    Two equivalent options:

    Option A — quick swap in the page

    Option B — edit script.js permanently 
    // script.js
const GGB_CONFIG = {
  materialId: "YOUR_MATERIAL_ID",
  appName: "graphing",     // graphing | geometry | 3d | classic | suite
  showToolBar: true,
  showAlgebraInput: true,
  showMenuBar: false
};

  4. (Optional) Use the iframe pattern instead

    If a sketch refuses to load via the API, GeoGebra also offers a direct iframe embed. Replace the mount element with:

    <iframe
  src="https://www.geogebra.org/material/iframe/id/YOUR_ID"
  width="100%" height="600"
  style="border:0" allowfullscreen
  title="GeoGebra activity"></iframe>

  5. Verify in class

    Reload the page, open GeoGebra Lab, and confirm the activity title appears. Encourage students to use the toolbar — everything keyboard navigates with Tab.
